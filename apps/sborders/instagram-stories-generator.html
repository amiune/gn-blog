📸 Instagram Export Guide

  1. Stories / Reels — full 9:16 layout; one PNG per slide at 1080×1920 for Stories and Reels
  2. All Formats — still one PNG per slide at 1080×1920, but content is centered in the dashed safe zone so Facebook/Instagram can center-crop to 4:5 feed or 1:1 square without cutting your message
  3. Switch format in the bar above to preview each mode before exporting
  4. Click Download All Stories to export all 5 slides for the selected mode
  5. Upload to Stories, Reels, Feed, or Meta ads — use All Formats when one asset must work across placements
📋 Template guide — multi-format generator (for other apps)

This page is a reusable pattern for SB app marketing: one HTML file renders fixed promotional slides and exports Instagram-ready PNGs. Copy it into static/apps/<app>/instagram-stories-generator.html and customize copy, colors, and mockups — keep the format architecture below.

Two modes, one HTML source

ModeBody classExportPurpose
Stories / Reels format-stories 1080×1920 · one PNG/slide Full vertical composition for Stories and Reels.
All Formats format-all 1080×1920 · one PNG/slide Same file size; layout compacts and centers so Meta can crop to 9:16, 4:5, or 1:1.

Safe zone (All Formats)

Platforms usually center-crop a vertical asset for feed placements. On 1080×1920, the strictest shared area is a centered 1080×1080 square (top/bottom 420px are “bleed”). The dashed box in preview marks that region (hidden on export via is-exporting). Keep headline, mockup, and CTA inside it; hide or shrink peripheral copy via body.format-all rules. Wider 4:5 crops (1080×1350) include more bleed—still safe if content stays centered.

Format bar behavior

  • Stories / Reels — sets body.format-stories; preview matches export.
  • All Formats — sets body.format-all; preview shows the crop-safe layout; export is still one 9:16 PNG per slide (suffix All-Formats-9x16).

CSS to tune when forking

  1. body.format-stories — default 9:16 preview size.
  2. body.format-all — block after “All Formats: still 9:16 export…” (centering, safe guide, per-#storyN hides).
  3. Per-story selectors e.g. body.format-all #story4 .feature-pill:nth-child(n+4).

Script constants when forking

  • FORMATS — stories and all (same dimensions; different bodyClass + filename suffix).
  • BG_FILL — background fill if html2canvas leaves transparency.
  • DOWNLOAD_PREFIX — e.g. SBOrders-IGStory-.

Export pipeline

html2canvas captures each .story at preview size × scale → drawn to 1080×1920 canvas → one PNG download per slide. No multi-pass export; cropping happens later in Meta Ads Manager or Instagram.
